# Global Superstore — Tableau Dashboard

## Project Overview
This project is an interactive Tableau dashboard developed as part of my Business Intelligence studies at Algonquin College.

Using the Global Superstore dataset, I explored sales performance, profitability, geographic trends, and customer behavior.

The dashboard was created by following a guided Tableau tutorial and applying data visualization techniques.

## Dashboard Features
- **Sales Seasonality:** Visualizes monthly sales patterns across product categories.
- **Sales Crosstab:** Compares sales performance using a highlighted table.
- **Global Sales and Profits:** Displays geographic sales distribution and profitability.
- **Sales by Sub-Category:** Compares product sub-categories based on sales and profit.
- **Customer Breakdown:** Examines the relationship between shipping costs and profit.
- **Interactive Dashboard:** Combines visualizations and category filters.
- **Tableau Story:** Presents findings through a structured visual narrative.
